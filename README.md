Group project for CS401


#Intructions for creating a pull request:
  1. Run all Junit tests, they must pass to continue.
  2. Commit all relevant code to your local branch
  3. Pull latest from origin main
  4. If any conflicts appear, resolve then.
     -recommit any changes
     -repeat step 3.
  6. Push your branch to GitHub
  7. Create Pull request in GitHub
  8. Notify others in Discord that you added the pull request.

Intructions for approving a pull request:
  1. Wait until you are at a safe stopping point in your branch
     -all changed have been saved and committed
  2. Pull code from the branch being merged
     -run Junit tests
     -review all changes
  3. post questions and comments
     -wait until all questions, comments have been resolved
  4. approved when ready
  5. merge pull request
  6. switch back to your branch
  7. pull changes from origin main
  8. resume coding
